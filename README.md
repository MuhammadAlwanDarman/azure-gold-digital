# Zaid Bin Tsabit Elite Academy

Buatkan sebuah Website Sekolah Premium Kelas Dunia dengan kualitas setara website universitas internasional dan sekolah elit. Website harus memiliki UI/UX yang sangat modern, futuristik, elegan, eksklusif, dan profesional. Setiap bagian memiliki animasi yang halus, interaksi yang menarik, dan pengalaman pengguna yang memukau.
